Como funciona?

  1. Faça upload de um documento judicial (decisão, sentença, acórdão).
  2. O hash SHA-256 é calculado no seu navegador — o documento nunca sai do seu computador.
  3. O hash é consultado na blockchain do VeredictChain.
  4. Se encontrado, você vê todos os metadados públicos: tribunal, magistrado, data e status.
